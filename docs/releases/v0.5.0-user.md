# HaTickets v0.5.0（用户版发布说明）

发布日期：2026-07-11

这是自 v0.4.1 以来最大的一次更新，核心是**让工具更安全、更值得信任**。日常抢票流程不变，但**正式抢票的命令改了**，请务必看下面第一条。

## ⚠️ 最重要的一个变化：正式抢票命令变了

为了防止「手滑误付款」，真实下单现在必须显式带 `--commit`：

- **安全探测**（不下单，推荐每次先跑）
  ```bash
  ./mobile/scripts/start_ticket_grabbing.sh --probe
  ```
- **正式抢票**（会真实提交订单）
  ```bash
  ./mobile/scripts/start_ticket_grabbing.sh --commit --yes
  ```

旧命令 `./mobile/scripts/start_ticket_grabbing.sh --yes`（不带 `--commit`）**已不再下单**，会直接报错并告诉你正确命令。正式抢票前脚本还会打印一遍「演出/票档/观演人/场次」摘要并倒数 3 秒，`Ctrl-C` 可随时取消。

## 你会直接感受到的变化

- **不会再手滑误付款**：安全探测和真实下单之间不再只差一个单词。命令敲错（比如 `--porbe`）会直接报错，绝不会偷偷帮你下单。
- **配置没填好会当场提醒**：如果 `config.jsonc` 里 `serial`、观演人还是模板占位符，一启动就中文报错，不用等跑到订单页才发现。
- **改配置不再丢注释**：切换探测/正式模式时，配置文件里的中文说明和护栏注释会原样保留，还会自动备份一份 `.bak`。
- **抢到票/占单不会误报成功**：安全探测遇到你账号里之前留下的未支付订单，会如实提醒「这是既有订单，不是本次抢的」，不再误报「抢票成功」。
- **多场次演出更稳**：音乐节这类多场次演出会强制先选场次，不会直接冲票档导致失败。
- **装环境更省心**：只要 `adb` 能用就行，不再强制你装整个 Android Studio、也不用手动设 `ANDROID_HOME`。
- **报错更看得懂**：找不到设备、观演人没填对、票价对不上等常见问题，都有明确中文提示。

## 抢票前必看：观演人怎么加

`config.jsonc` 里的 `users` 必须是**已经在大麦 App 里添加成功**的真实观演人。添加方法：打开大麦 App →「我的」→「观演人 / 常用观演人」→「添加」，填真实姓名和证件信息保存。配置里的名字要和这里**逐字一致**，人数就是买几张票。

## 推荐使用流程

1. 安装依赖
   ```bash
   poetry install
   ```
2. 连接安卓真机，确认 `adb devices` 能识别，且大麦 App 已登录、观演人已添加
3. 先做安全探测（不下单）
   ```bash
   ./mobile/scripts/start_ticket_grabbing.sh --probe
   ```
4. 正式抢票
   ```bash
   ./mobile/scripts/start_ticket_grabbing.sh --commit --yes
   ```

## 自然语言入口（可选）

```bash
./mobile/scripts/run_from_prompt.sh --mode probe --yes "给张三抢 7 月 18 号上海大鱼海棠十周年演出内场票，价位 1399 元"
```

为避免误下单，自然语言入口只做「探测」，不提供自动真实下单。

## 从 v0.4.1 升级注意

- `git pull && poetry install` 即可。
- **正式抢票命令改成 `--commit --yes`**（最重要，见开头）。
- 确认 `config.jsonc` 里 `serial`、观演人都是真实值——占位符现在会启动即报错。
- 如果你写过自动化脚本 / cron，注意脚本失败时退出码不再总是 0（详见开发文档「退出码与运行摘要」）。

## 已知边界

- 线上库存、风控、验证码会影响结果，自动化不保证 100% 成功。
- 建议每次正式抢票前先跑一次 `--probe` 确认页面识别正常。
- 多场次（音乐节）选择仍偶有边界场景。
